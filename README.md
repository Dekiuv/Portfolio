# 🌐 Portfolio Personal - Diego Roque Valero

Este es mi portfolio personal desarrollado desde cero con HTML, CSS y JavaScript. Aquí presento de forma estructurada mi experiencia, formación, habilidades técnicas y proyectos más relevantes en el ámbito del desarrollo, la inteligencia artificial y la administración de sistemas.

---

## 🧠 ¿Qué encontrarás en este portfolio?

- 🧾 Información personal y profesional  
- 🎓 Formación académica y cursos  
- 🧩 Aptitudes técnicas e idiomas  
- 💼 Experiencia laboral  
- 🚀 Proyectos destacados con descripciones y enlaces  

---

## 💡 Tecnologías utilizadas

- `HTML5`
- `CSS3`
- `JavaScript`
- `Font Awesome` para iconografía
- `Responsive Design` con Flexbox y Grid
- `Modal personalizado` con animaciones y lógica en JS
